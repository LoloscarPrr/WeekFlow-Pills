# WeekFlow Pills

Aplicación Android separada de WeekFlow para organizar medicamentos prescritos de forma simple.

## V1 congelada

- Pantalla **Hoy** con tomas ordenadas por hora.
- Registro **Tomado / Omitido** con hora real.
- Medicamentos con nombre, dosis indicada, instrucciones, horarios y días.
- Recordatorios locales.
- Stock simple y aviso de stock bajo.
- Historial.
- Datos guardados localmente con SQLite.
- Interfaz oscura, grande y simple, basada en WeekFlow.

## Seguridad

WeekFlow Pills **no diagnostica, no recomienda dosis y no modifica tratamientos**. Solo registra la información ingresada por la persona usuaria y recuerda los horarios configurados. Ante una dosis olvidada o dudas sobre un tratamiento, se debe seguir la indicación del profesional tratante o farmacéutico.
